# Oasis Infobyte Level 1 Task 3 - Temperature Converter

This is a responsive temperature converter made using HTML, CSS, and JavaScript.

## Files
- `index.html`
- `style.css`
- `script.js`
- `README.md`

## How to run
1. Put all files in the same folder.
2. Open `index.html` in your browser.

## Features
- Convert Celsius, Fahrenheit, and Kelvin
- Clean modern UI
- Responsive layout
- Input validation

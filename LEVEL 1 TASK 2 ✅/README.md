# Oasis Infobyte Level 1 Task 2 - Portfolio Website

This is a clean, responsive personal portfolio website made with HTML, CSS, and JavaScript.

## Files
- `index.html`
- `style.css`
- `script.js`

## How to run
1. Put all files in the same folder.
2. Open `index.html` in your browser.

## Features
- Attractive hero section
- About, skills, projects, and contact sections
- Responsive design for mobile and desktop
- Mobile navigation menu

## Customization
Replace the sample details like email, phone number, LinkedIn, and project text with your own information.
